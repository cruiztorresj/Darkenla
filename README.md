# Darkenla
Dark theme for websites.

Right now this is an extension for the Vivaldi Web Browser, although it should be possible to install it on Chrome with little to none modifications in the installation process.

## Background and technical.
I built this web extension for my own use, so it is easy for the eyes while reading documentation for example. At present time not all the HTML elements are there to be styled, I remember styling only the `body` at the beginning and style more HTML elements as needed. At some point I got tired of copy-pasting the JavaScript code into the web developer console and I decided to go on creating this web browser extension.

There are basically like five colors overall since the intention was merely for reading purposes, given that I only visit a very small (I just realized I did not include this element!) set of websites it may be the case that applying Darkenla to your favorite website will result in some parts of the content you are seeing not being aligned with the overall intended dark theme. I am using this web extension myself and I will try to pay attention to the styled websites, so more elements may be added on the go.

I am positive you are a Software development related person or tech savvy, because ideally these extensions are meant to be installed from web stores. So anyway, I am mentioning it due to the fact that perhaps you will be tempted to feel a little bit picky about having a ternary operator in the actual arguments while invoking `setAttribute`, this was just a way to reduce boilerplate but features like this should not be abused in my opinion.  

A quick search was made prior to go definitively with the name `Darkenla`. Other than being some sort of a name for a character on a website, Darkenla seems not to be associated with some other Software, most likely it is a name on a existing theme. 

In the hope in helps someone, easy reading!
